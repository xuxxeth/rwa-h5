# React Rules

## Component
- Function components only
- Use hooks only
- Keep components reusable and clean

## Naming
- MUST use `TittleBar` (NOT TitleBar)

## Structure
- pages: `src/views/<module>/index.tsx`
- sub components: `src/views/<module>/components/`
- shared: `src/components/`

## Routing
- Defined in `src/routes/index.tsx`
- Use React.lazy for pages
